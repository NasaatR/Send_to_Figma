# Send to Figma

[English](README.md)

**Правая кнопка по картинке → Отправить в Figma.** Изображения добавляются в аккуратную коллекцию по порядку.

Нужны Windows 10/11 x64 или ARM64, Chrome/Edge и приложение Figma Desktop с правом редактирования файла. Node.js, Python и ключ Figma API не нужны.

[Скачать проверенную сборку Windows](https://github.com/NasaatR/Send_to_Figma/releases/tag/v1.3.0) · [Репозиторий](https://github.com/NasaatR/Send_to_Figma)

## Установка один раз

1. Распакуй **весь** архив `Send-to-Figma-1.3.0-Windows.zip`.
2. Дважды нажми **Setup.exe**. Откроется инструкция с готовыми путями. Помощник, расширение и плагин копируются в постоянную папку; права администратора не запрашиваются.
3. В адресную строку Chrome вставь `chrome://extensions` (для Edge — `edge://extensions`). Включи **Режим разработчика → Загрузить распакованное**. Выбери папку:
   `%LOCALAPPDATA%\SendToFigma\app\extension`
4. Откроется страница подключения. В **Figma Desktop** открой нужный файл, нажми ПКМ по холсту → **Plugins → Development → Import plugin from manifest…**. Вставь путь, который копируется на странице расширения:
   `%LOCALAPPDATA%\SendToFigma\app\figma-plugin\manifest.json`
5. Запусти **Send to Figma · Receiver**. Он подключится автоматически: Setup.exe уже настроил связь с этим компьютером. Код и кнопка старта не нужны.
6. В расширении нажми **Отправить тестовое изображение**. В Figma должна появиться карточка; расширение покажет подтверждение вставки. Тестовую карточку можно удалить.

Всё. Теперь **ПКМ по изображению на сайте → Отправить в Figma**. Распакованный архив можно удалить. Если страница подключения не открылась, нажми значок расширения → **Подключение и проверка**. Обнови веб-страницы, которые были открыты до установки.

## Что удобнее в 1.3.0

- Автоматическое подключение после Setup.exe и автоматический приём при запуске плагина. Ручной код спрятан в запасной раздел.
- На сайте видно: подготовка, ожидание приёмника, подтверждённая вставка или ошибка.
- Диагностика копируется одной кнопкой в Figma и расширении; последние ошибки сохраняются между запусками браузера.


- Миниатюры, поиск и фильтры очереди: все, в работе, ошибки, история.
- Получатель всегда виден; источник открывается отдельной кнопкой.
- Пауза сохраняется между запусками. Текущая вставка завершается, следующие ждут.
- Ошибки можно повторить одной кнопкой. Отмена ожидающих и очистка истории требуют подтверждения; картинки в Figma сохраняются.
- В Figma есть готовые раскладки: сетка, лента и компактная. Сначала это черновик; для применения нажми «Сохранить».

## При следующих запусках

Открой нужный файл Figma и запусти приёмник. Он сам восстановит коллекцию и подключится. Повторно устанавливать компоненты и копировать код не нужно. Оставляй приёмник запущенным; запуск другого плагина может завершить его работу.

Без открытого приёмника готовые изображения сохраняются в локальной очереди. После подключения они отправятся в закреплённую коллекцию. Выделение другого слоя не меняет получателя. Изображения, отправленные до первого запуска приёмника, принимаются автоматически. Если прежняя коллекция сейчас отключена, новые отправки идут в открывшийся приёмник; уже назначенные изображения сохраняют прежнего получателя. Другой активный приёмник не перехватывает отправки.

**Раскладка** управляет колонками, размерами, промежутками и подписями. Новые настройки действуют на следующие карточки. **Перестроить существующие карточки** меняет только управляемые карточки; действие отменяется в Figma через Ctrl+Z. Повтор старой неудачной вставки добавляется в конец; перестройка возвращает порядок номеров.

## Если не получилось

- **Manifest error / Invalid value for allowedDomains:** обновись до 1.2.2 или новее через Setup.exe, затем повтори импорт `%LOCALAPPDATA%\SendToFigma\app\figma-plugin\manifest.json`. Ранние сборки использовали адрес, который Figma отклоняет. Удалять данные или устанавливать расширение заново не нужно.
- **Нет связи с помощником:** нажми **Подключение и проверка → Проверить подключение**. Если установка не завершилась — повтори Setup.exe из полного архива. Если обновлению мешает запущенный процесс, закрой браузер и повтори установку.
- **Figma не подключена:** запусти приёмник в нужном файле. Он подключается сам; если помощник ещё не запущен, открой меню расширения. Проверь право редактирования. Если появляется запрос доступа к локальной сети для этого приёмника, разреши его.
- **Картинка осталась в очереди:** проверь имя получателя и блокировку коллекции/её родительского слоя. Для ошибки вставки доступна кнопка повтора; исходник без сохранённых данных нужно отправить с сайта заново.
- **Исходник недоступен:** выдели предложенную область. Это будет снимок экрана; Esc отменяет выделение. Для сайта со своим меню используй кнопку выделения области в расширении.
- **Нужна помощь:** нажми значок копирования в шапке расширения или **Диагностика** внизу приёмника Figma. На странице подключения есть та же кнопка. Добавь текст ошибки и версию Figma. Код подключения и файл config.json присылать не нужно.

## Обновить, удалить, передать

Обновление: останови приёмник, запусти Setup.exe из нового архива, нажми ↻ у расширения на странице расширений и открой приёмник заново. Очередь и код сохраняются.

Если была установлена 1.0.0 из Downloads: удали старую запись расширения и загрузи постоянную папку выше; настройку вида браузерной панели при необходимости задай заново. В Figma заново импортируй плагин по постоянному пути. Очередь помощника и картинки Figma сохраняются.

Удаление: **Параметры Windows → Приложения → Установленные приложения → Send to Figma**, затем удали расширение и запись плагина Development. Папка `%LOCALAPPDATA%\SendToFigma\data` сохраняется для восстановления. Удаляй её вручную только если очередь больше не нужна. Изображения в Figma останутся.

Другому человеку передавай **исходный ZIP**, а не установленную папку: в установленном коде приёмника находится локальный ключ. Он выполнит те же шаги, а его компьютер создаст отдельный код подключения.

## Что учитывать

Это версия для ручной установки, без публикации в магазинах Chrome и Figma. Автоматические проверки установщика Windows и интерфейса браузера вынесены в GitHub Actions. Вставка в настоящий Figma Desktop, установка расширения в браузер и работа на ARM64-компьютере остаются отдельными непроверенными границами; подробности — в TESTING.md. EXE не подписаны сертификатом: Windows или политика организации могут ограничить запуск. Контрольная сумма проверяет целостность, но не заменяет цифровую подпись.

Получить оригинал с абсолютно любого сайта невозможно. Поддерживаемые изображения ограничены 20 МБ и 4096 px по стороне; более крупные уменьшаются пропорционально. PNG/JPEG/GIF сохраняются без перекодирования, когда возможно; WebP/AVIF/SVG преобразуются в PNG. Защищённые и служебные страницы могут запрещать захват. Очередь: до 200 незавершённых изображений и 256 МБ. Маленькие локальные миниатюры сохраняются с историей: до 500 записей, последние 20 видны в панели. Очистка истории не удаляет слои Figma.

Передача локальная, через `127.0.0.1:47821`. Внешнего сервера, аналитики и наблюдения за буфером обмена нет. Настройки импорта/экспорта не содержат код подключения.
