Приёмник в Figma Desktop

Открой нужный файл в приложении Figma. ПКМ по холсту → Plugins → Development → Import plugin from manifest…

Запусти Send to Figma · Receiver, вставь код и нажми Начать приём.

При следующих запусках достаточно открыть этот плагин и нажать «Начать приём».

Готово к работе

ПКМ по изображению → Отправить в Figma. Картинки добавляются в коллекцию по порядку. Если исходник недоступен, выдели область для снимка экрана.

Оставляй приёмник Figma запущенным. Если он закрыт, готовые изображения останутся в локальной очереди.
